# syrvis/.github

The Syrvis organisation's front page and its docs site.

- `profile/README.md` is the page GitHub shows at github.com/syrvis.
- `docs/` is the site GitHub Pages serves: the user guide (`docs/guide/`), the design docs, one per component (`docs/design/`), and how Syrvis is proven (`docs/provability/`).
- `make check` runs the hygiene scan and the em-dash scan; nothing is pushed while it is red.
